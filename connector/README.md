# Conector WhatsApp Web (não oficial)
Serviço isolado, sem domínio público. Root directory /connector. Montar volume persistente em /session, uma réplica. Configurar WA_CONNECTOR_SECRET igual ao da aplicação; CARIRI_APP_URL aponta para a aplicação. Na aplicação configurar WA_CONNECTOR_URL para o DNS privado do conector com porta 8080 e WA_CONNECTOR_SECRET. Aplicar schema Prisma aditivo antes de ativar o conector. QR disponível somente a ADMIN. Validar ambiente de teste, duplicidade, autorização, reconexão e perda de internet antes de produção. Não cria despacho automaticamente. Não há garantia de entrega nem suporte oficial da Meta.

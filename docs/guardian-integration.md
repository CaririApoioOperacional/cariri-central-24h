# Guardian Parceiro — contrato interno do conector CARIRI
O painel não é um substituto operacional antes da homologação. O link de login é o portal oficial Intelbras. Não coletar credenciais, cookies ou tokens da conta via CARIRI. Não contornar bloqueios de iframe, MFA ou políticas do fabricante.
O endpoint POST /api/guardian/snapshot é um contrato **interno da CARIRI**, não uma API Intelbras. Está desativado por padrão até configuração de GUARDIAN_CONNECTOR_SECRET no servidor, com Bearer de uso exclusivo do conector autorizado. Não publicar este segredo no cliente. O conector deverá produzir snapshots completos, não incrementais, incluindo observedAt ISO, devices com id,name,connection ONLINE/OFFLINE/UNKNOWN,armed ARMED/DISARMED/PARTIAL/UNKNOWN,battery e power NORMAL/FAULT/UNKNOWN, incidents com id,deviceId,type ALARM/PANIC/TAMPER/COMMUNICATION/BATTERY/POWER/OTHER,description,occurredAt ISO,open boolean. Uma leitura com idade superior a 120s é considerada desatualizada. Não inventar estado, não substituir ausência de leitura por zero. Nenhum comando, protocolo ou despacho é disparado por esta API. Antes de habilitar o conector, confirmar documentação e autorização do fabricante; testar em equipamento próprio. O painel usa a leitura mais recente, não é arquivo histórico integral de eventos.
